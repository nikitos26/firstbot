# AI Art Bot 🤖🎨

Telegram бот для генерации и редактирования изображений с помощью искусственного интеллекта.

## 🚀 Возможности

- 🖼️ **Генерация изображений** по текстовому описанию
- ✏️ **Редактирование изображений** с помощью AI
- 🎬 **Обработка видео** (в разработке)
- 🌍 **Работа без VPN** - использует сервисы, доступные в Беларуси

## 📋 Требования

- Python 3.9+
- Telegram Bot Token (получить у @BotFather)
- API ключи для AI сервисов

## 🛠️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd firstbot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл, добавив ваши токены
```

4. **Запустите бота:**
```bash
python main.py
```

## ⚙️ Конфигурация

Создайте файл `.env` с следующими переменными:

```env
# Telegram Bot Token (получи у @BotFather)
BOT_TOKEN=your_bot_token_here

# AI Service API Keys
KANDINSKY_API_KEY=your_kandinsky_api_key_here
KANDINSKY_API_URL=https://api-key.fusionbrain.ai

# Database
DATABASE_URL=sqlite:///bot.db

# Logging
LOG_LEVEL=INFO
```

## 🎯 Использование

### Команды бота:
- `/start` - Начать работу с ботом
- `/help` - Получить справку
- `/generate` - Генерация изображения
- `/edit` - Редактирование изображения

### Генерация изображений:
1. Отправьте текстовое описание желаемого изображения
2. Дождитесь обработки (может занять несколько минут)
3. Получите готовое изображение

### Редактирование изображений:
1. Загрузите изображение в чат
2. Отправьте описание желаемых изменений
3. Получите отредактированное изображение

## 🔧 Поддерживаемые форматы

- **Изображения:** JPG, PNG, WebP
- **Видео:** MP4, AVI, MOV (в разработке)

## 🚀 Развертывание

### Локальный запуск:
```bash
python main.py
```

### Docker (опционально):
```bash
docker build -t ai-art-bot .
docker run -d --env-file .env ai-art-bot
```

### VPS/Хостинг:
1. Загрузите код на сервер
2. Установите зависимости
3. Настройте переменные окружения
4. Запустите с помощью systemd или supervisor
